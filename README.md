## 🌟😎 ЧТО ЭТО ЗА КИБЕРХУЙНЯ? 😎🌟
**XenoneI2P** — 🧠 ультрасовременный, 🔮 технологичный и абсолютно 🥷 хакерский торрент-клиент на **Python** с кастомным графическим интерфейсом **CustomTkinter**! 
Мы выкинули нахуй убогий серый дизайн из 1990-х и завернули всё в сочный **Dark/Light Mode**, добавили многоязычный **i18n** (поддерживаем инглиш для буржуев и великий русский для своих) и прикрутили графики скоростей, от которых у вас встанет... **производительность системы!** 📈💻✨

---

## 🔥💎 ПОЧЕМУ ИМЕННО WE? (ФУНКЦИОНАЛ НА МИЛЛИОН) 💎🔥
*   🎨 **CustomTkinter GUI** — выглядит так дорого, что ваши коллеги по цеху подумают, будто вы написали операционку на ассемблере.
*   🌍 **i18n Localisation** — переключение языков `EN` / `RU` на лету одним кликом! 
*   📁 **Smart File Picker** — добавляй `.torrent` файлы через нативные диалоговые окна (с защитой от дураков, проверяющих расширения!).
*   🛑 **Error Handling** — если что-то пойдет по пизде, приложение не упадет в молчанку, а выдаст сочное модальное окно с ошибкой.
*   ⚡ **Real-time Refresh** — автообновление каждые 2 секунды без зависаний интерфейса!

Without trolling.
So, for launch the app you can use python3.
```
# debian (from root)
apt-get install python3-pip # this will automatic download python

git clone https://github.com/wipedlifepotato/XenoneI2P
python3 -m venv .
./bin/pip3 install -r requirements.txt
./bin/python3 main.py
```

Add to your tunnels.conf
```
[MyTorrents]
type=torrents
trackers=http://tracker2.postman.i2p/announce.php
torrentsdir=#""""""""$PATH""""""""
rpcport=9191 # or an another
rpcpath=mytorrents # set it but or an another
```
